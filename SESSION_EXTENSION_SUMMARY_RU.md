# Продление Сессий - Обзор Возможностей

## ✅ Да, сессии можно продлевать автоматически!

Реализованы две ключевые команды:

---

## 🔄 1. Автоматическое Продление (Без входа в систему)

### Команда
```bash
npm run extend-session
```

### Что делает
- ✅ Открывает браузер **в невидимом режиме** (headless)
- ✅ Загружает сохраненные **cookies**
- ✅ Переходит на Qwen для **обновления сессии**
- ✅ Извлекает и сохраняет **новый токен**
- ✅ Закрывает браузер

### Когда использовать
- Регулярное обслуживание (каждые 6-12 часов)
- **ДО** истечения токена
- Можно автоматизировать через **cron**

### Автоматизация
```bash
# Продлевать каждые 6 часов
crontab -e
0 */6 * * * cd /path/to/FreeQwenApi && npm run extend-session
```

---

## 🔐 2. Создание Новой Сессии (С входом в систему)

### Команда
```bash
npm run create-session-archive
```

### Что делает
- ✅ Открывает браузер **в видимом режиме**
- ✅ Вы **входите в систему** вручную
- ✅ Сохраняет сессию и **cookies**
- ✅ Создает **ZIP архив**

### Когда использовать
- Первая настройка
- Когда сессия **полностью истекла**
- Когда продление не работает

---

## 📊 Сравнение

| Функция | Продление | Создание |
|---------|-----------|----------|
| **Вход в систему** | Не нужен | Нужен вручную |
| **Время** | ~10 секунд | ~1-2 минуты |
| **Браузер** | Невидимый | Видимый |
| **Автоматизация** | Можно через cron | Только вручную |
| **Когда** | Регулярно | При необходимости |

## 🎯 Рабочий Процесс

### Начальная Настройка
```bash
# 1. Создать сессию (один раз)
npm run create-session-archive

# 2. Настроить автоматическое продление
crontab -e
# 0 */6 * * * cd /path/to/FreeQwenApi && npm run extend-session
```

### Ежедневное Использование
```bash
# Ничего! Всё автоматизировано
# Или вручную при необходимости:
npm run extend-session
```

### Когда Что-то Сломалось
```bash
# Повторная авторизация
npm run create-session-archive
```

## 💡 Советы

### 1. Настройте Уведомления Telegram

Добавьте в `.env`:
```bash
TELEGRAM_BOT_TOKEN=ваш_токен
TELEGRAM_USER_IDS=ваш_id
TOKEN_EXPIRY_WARNING_MS=7200000  # Предупреждать за 2 часа
```

### 2. Логи Продления

```bash
# Сохранять логи
npm run extend-session >> logs/extension.log 2>&1
```

### 3. Проверка Статуса

```bash
# Проверить токены
npm start

# Искать сообщения:
# ✅ Аккаунт активен
# ⚠️ Токен истекает
# ❌ Токен истек
```
