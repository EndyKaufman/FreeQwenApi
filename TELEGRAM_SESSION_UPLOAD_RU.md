# Telegram Bot - Загрузка Сессий

## 🎯 Что это такое

Telegram бот позволяет **удаленно загружать сессии Qwen** через архивы:
- 📦 **Принимает ZIP/7z архивы** с папкой session
- 🔄 **Автоматически распаковывает** в нужную директорию
- 🚀 **Перезапускает сервис** после обновления сессий
- 📊 **Отправляет уведомления** о статусе токенов

---

## 📋 Инструкция: Создание папки session

### Способ 1: Локальная установка (Node.js)

**Требования:**
- Node.js v23.11.1 или выше
- npm

**Шаги:**

1. **Склонируйте репозиторий:**
   <code>git clone https://github.com/EndyKaufman/FreeQwenApi</code>

2. **Перейдите в директорию:**
   <code>cd FreeQwenApi</code>

3. **Установите зависимости:**
   <code>npm install</code>

4. **Запустите сервер:**
   <code>npm start</code>

5. **Выберите опцию 1** - добавить аккаунт

6. **Войдите в аккаунт Qwen** в открывшемся браузере

7. **Токен сохранится автоматически** в папку <code>session/</code>

**Структура папки session:**

<code>session/</code>
├── <code>accounts/</code>
│   ├── <code>acc_123456/</code>
│   │   └── <code>token.txt</code>
│   └── <code>acc_789012/</code>
│       └── <code>token.txt</code>
├── <code>tokens.json</code>
└── <code>auth_token.txt</code>

---

### Способ 2: Docker

**Требования:**
- Docker
- Docker Compose

**Шаги:**

1. **Сначала создайте сессию локально** (Способ 1)

2. **Соберите Docker образ:**
   <code>docker compose build --no-cache</code>

3. **Запустите контейнер:**
   <code>docker compose up -d</code>

4. **Папка session будет доступна** через volume mapping

## 📦 Создание архива для загрузки

### Вариант A: ZIP (рекомендуется)

```bash
zip -r session_backup.zip session/
```

### Вариант Б: 7z

```bash
7z a session_backup.7z session/
```

### ✅ Правильная структура архива:

```
session_backup.zip
└── session/
    ├── accounts/
    │   ├── acc_123/
    │   │   └── token.txt
    │   └── acc_456/
    │       └── token.txt
    ├── tokens.json
    └── auth_token.txt
```

### ❌ Неправильная структура:

```
backup.zip
├── accounts/          ← Нет папки session/
│   └── acc_123/
└── tokens.json
```

## 📱 Загрузка архива в Telegram

### Пошаговая инструкция:

1. **Откройте вашего бота** в Telegram

2. **Нажмите 📎 (скрепка)** для прикрепления файла

3. **Выберите "Файл"** (НЕ "Фото" или "Галерея"!)

4. **Найдите архив** на вашем устройстве

5. **Отправьте файл** боту

6. **Дождитесь ответа** от бота

### Что сделает бот:

```
⏳ Загрузка файла session_backup.zip...
✅ Файл загружен. Распаковка...
✅ Архив успешно распакован!

📂 Папка session обновлена
🔄 Сервис будет перезапущен...

🔄 Перезапуск сервиса...
⏱️ Сервис будет перезапущен в течение 5 секунд
```

### Что произойдет дальше:

1. ⏱️ **Через 3-5 секунд** сервис автоматически перезапустится
2. 📂 **Новые сессии будут загружены** из архива
3. ✅ **Можно продолжать работу** с новыми аккаунтами

## ⚙️ Настройка бота

### В .env файл добавьте:

```bash
# Токен бота от @BotFather
TELEGRAM_BOT_TOKEN=123456789:ABCdefGHIjklMNOpqrsTUVwxyz

# Ваш ID от @userinfobot
TELEGRAM_USER_IDS=123456789

# Время предупреждения токенов (по умолчанию 1 час)
TOKEN_EXPIRY_WARNING_MS=3600000
```

### Пересоберите контейнер:

```bash
docker-compose build
docker-compose up -d
```

## 🔍 Как это работает

```
Пользователь отправляет архив
         ↓
Бот скачивает файл
         ↓
Распаковывает в session/
         ↓
Создает файл .restart_flag
         ↓
Завершает процесс (код 42)
         ↓
Startup скрипт ловит код 42
         ↓
Ждет 3 секунды
         ↓
Перезапускает сервис
         ↓
Новые сессии загружены ✅
```

## ❗ Решение проблем

### "Архив не содержит папку session"

**Проблема:** Неправильная структура архива

**Решение:**
```bash
# Правильно:
zip -r session_backup.zip session/

# Неправильно:
cd session && zip -r ../backup.zip *
```

### Файл не принимается

**Проверьте:**
1. Формат: только <code>.zip</code> или <code>.7z</code>
2. Размер: максимум 50MB
3. Отправляйте как **файл**, не как фото

### Сервис не перезапускается

**Ручной перезапуск:**
```bash
docker-compose restart
```

**Проверка:**
```bash
# Проверить логи
docker-compose logs --tail=50

# Проверить статус
docker-compose ps
```

### Бот не отвечает

**Проверьте:**
1. <code>TELEGRAM_BOT_TOKEN</code> правильный
2. Бот не заблокирован
3. Есть интернет до Telegram API

```bash
# Проверка подключения
docker-compose exec qwen-proxy curl https://api.telegram.org
```
