# Быстрая настройка проверки обновлений

## Включение проверки

Проверка обновлений **включена по умолчанию**. Вам не нужно ничего настраивать!

### Если хотите отключить

Добавьте в `.env` файл:

```env
ENABLE_VERSION_CHECK=false
```

### Шаг 2: Убедитесь что Telegram настроен

```env
TELEGRAM_BOT_TOKEN=ваш_токен_бота
TELEGRAM_USER_IDS=ваш_user_id
```

### Шаг 3: Перезапустите приложение

```bash
# Docker
docker compose down
docker compose up -d

# npm
npm start

# Из кода
npm start
```

## Что произойдет

### При запуске

Вы увидите в консоли:

```
🚀 Сервис запущен! v1.0.20
```

Или если есть обновление:

```
🚀 Сервис запущен! v1.0.20 (доступна v1.0.20)
```

### Каждый час

Приложение будет проверять:
- **Docker**: Docker Hub на новые теги
- **npm**: npm registry на новые версии
- **Git**: GitHub Releases на новые релизы

### Когда найдено обновление

**В консоли:**
```
📦 Доступна новая версия: 1.0.20 (текущая: 1.0.20)
📅 Опубликована: 10.06.2026, 14:30 (2 ч. назад)
🔗 Режим: docker
```

**В Telegram (раз в сутки днем):**
```
📦 Доступно обновление!

🔹 Текущая версия: 1.0.20
🔹 Новая версия: 1.0.20
📅 Опубликована: 10.06.2026, 14:30
🕐 2 ч. назад

🔗 Режим запуска: docker
```

### Команда /status

В Telegram боте команда `/status` покажет:

```
🚀 Сервис запущен! v1.0.20

📦 Версия:
Текущая: v1.0.20
Режим: docker
Доступна: v1.0.20 (опубликована: 10.06.2026, 14:30)
```

## Отключение проверки

Добавьте в .env:

```env
ENABLE_VERSION_CHECK=false
```

## Важные моменты

✅ **Безопасно**: Ошибки проверки не ломают приложение
✅ **Тихо**: Telegram уведомления только раз в сутки днем
✅ **Умно**: Проверка каждый час, но уведомления редко
✅ **Автоматически**: Сам определяет Docker/npm/Git

❌ **Не обновляет автоматически**: Только сообщает о наличии
❌ **Не ломается**: Ошибки только в логах, не в Telegram

## Режимы работы

| Как запущено | Что проверяет |
|-------------|---------------|
| Docker контейнер | Docker Hub теги |
| npm пакет (global) | npm registry |
| Из репозитория | GitHub Releases |

## Примеры для разных способов запуска

### Docker Compose

```yaml
version: '3.8'

services:
  qwen-api-proxy:
    image: endykaufman/qwen-api-proxy:latest
    environment:
      # ENABLE_VERSION_CHECK=true  # Already enabled by default
      - TELEGRAM_BOT_TOKEN=8123456789:AAxxxxxx
      - TELEGRAM_USER_IDS=123456789
    ports:
      - "3264:3264"
```

### npm global

```bash
npm install -g qwen-api-proxy

# Создайте .env в рабочей директории (version check already enabled)
echo "TELEGRAM_BOT_TOKEN=8123456789:AAxxxxxx" > .env
echo "TELEGRAM_USER_IDS=123456789" >> .env

# Запустите
qwen-api-proxy
```

### Из исходного кода

```bash
git clone https://github.com/EndyKaufman/FreeQwenApi.git
cd FreeQwenApi

# Добавьте в .env (version check already enabled)
cat >> .env << EOF
TELEGRAM_BOT_TOKEN=8123456789:AAxxxxxx
TELEGRAM_USER_IDS=123456789
EOF

npm start
```

## Вопросы и ответы

### ❓ Как часто проверяется?
Каждый час (60 минут).

### ❓ Как часто приходят уведомления?
Раз в сутки в дневное время (10:00-18:00).

### ❓ Что если проверка упадет с ошибкой?
Ничего страшного. Ошибка только в логах. Приложение продолжает работать.

### ❓ Можно проверить вручную?
Пока нет. В будущем будет команда `/checkupdates`.

### ❓ Приложение обновляется автоматически?
Нет! Только сообщает о наличии обновления. Обновлять нужно вручную.

### ❓ Какие данные отправляются?
Никакие. Только GET запросы к публичным API.

### ❓ Работает ли без Telegram?
Да! В консоль все равно будет писать о обновлениях.
