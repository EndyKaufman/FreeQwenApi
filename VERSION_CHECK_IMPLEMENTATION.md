# Автоматическая проверка обновлений - Реализация

## Обзор изменений

Реализована система автоматической проверки обновлений для Docker, npm и Git repository с уведомлениями в Telegram и консоли.

## Что было сделано

### 1. Создан новый модуль проверки версий

**Файл:** `src/utils/versionChecker.js`

**Функциональность:**
- Автоматическое определение режима запуска (Docker/npm/Git)
- Проверка последней версии из соответствующего источника
- Периодическая проверка каждый час
- Уведомления в Telegram раз в сутки днем (10:00-18:00)
- Вывод информации в консоль при обнаружении обновления
- Безопасная обработка ошибок (не приводят к падению приложения)

**Основные функции:**
- `getRunMode()` - определяет режим запуска
- `getCurrentVersion()` - читает текущую версию из package.json
- `checkDockerVersion()` - проверяет Docker Hub
- `checkNpmVersion()` - проверяет npm registry
- `checkGitVersion()` - проверяет GitHub Releases
- `checkForUpdates()` - главная функция проверки
- `getVersionInfo()` - получает информацию для отображения
- `startPeriodicVersionCheck()` - запускает периодическую проверку

## Как это работает

### Определение режима

```javascript
function getRunMode() {
    // Docker: существует /.dockerenv
    if (fs.existsSync('/.dockerenv')) {
        return 'docker';
    }
    
    // npm: QWEN_API_PROXY_GLOBAL=true
    const isGlobalInstall = process.env.QWEN_API_PROXY_GLOBAL === 'true';
    if (isGlobalInstall) {
        return 'npm';
    }
    
    // Git: все остальные случаи
    return 'git';
}
```

### Источники проверки

| Режим | URL | Что проверяет |
|-------|-----|---------------|
| Docker | `https://hub.docker.com/v2/repositories/endykaufman/qwen-api-proxy/tags/` | Последний тег (кроме latest) |
| npm | `https://registry.npmjs.org/qwen-api-proxy/latest` | Последняя published версия |
| Git | `https://api.github.com/repos/EndyKaufman/FreeQwenApi/releases/latest` | Последний release |

### Частота проверки

1. **При старте**: Сразу проверяет и показывает результат
2. **Каждый час**: Проверяет наличие обновлений
3. **Telegram уведомления**: 
   - Только если прошло 24+ часа с последнего уведомления
   - Только в дневное время (10:00-18:00)
   - Только если найдено обновление

### Обработка ошибок

**Важно**: Все ошибки при проверке версий:
- ❌ НЕ приводят к падению приложения
- ❌ НЕ отправляются в Telegram
- ✅ Только логируются в консоль с уровнем `error` или `debug`

```javascript
try {
    // проверка версии
} catch (error) {
    logError('Ошибка проверки версии', error);
    return null; // безопасно возвращаем null
}
```

## Примеры использования

### Docker Compose

```yaml
version: '3.8'

services:
  qwen-api-proxy:
    image: endykaufman/qwen-api-proxy:latest
    environment:
      - ENABLE_VERSION_CHECK=true
      - TELEGRAM_BOT_TOKEN=your_token
      - TELEGRAM_USER_IDS=your_user_id
    volumes:
      - ./session:/app/session
      - ./logs:/app/logs
    ports:
      - "3264:3264"
```

### npm global

```bash
ENABLE_VERSION_CHECK=true qwen-api-proxy
```

### Из исходного кода

```bash
# В .env файле:
ENABLE_VERSION_CHECK=true

# Запуск:
npm start
```

## Тестирование

### Проверка работы

1. Включите проверку обновлений:
   ```env
   ENABLE_VERSION_CHECK=true
   ```

2. Запустите приложение:
   ```bash
   npm start
   ```

3. Проверьте логи:
   ```
   🔍 Проверка обновлений (режим: git, текущая версия: 1.0.20)...
   ✅ Используется последняя версия: 1.0.20
   ```

4. Отправьте `/status` в Telegram бот - должна отобразиться версия

### Принудительная проверка

Временно измените версию в package.json на более старую, чтобы увидеть уведомление:
```json
{
  "version": "1.0.0"  // временно измените для теста
}
```
