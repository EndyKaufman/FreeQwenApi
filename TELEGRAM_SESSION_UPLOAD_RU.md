# Telegram Bot - Загрузка Сессий

## 🎯 Что добавлено

Теперь Telegram бот умеет:
- **Принимать ZIP/7z архивы** с папкой session
- **Автоматически распаковывать** в нужную директорию
- **Перезапускать сервис** после обновления сессий
- **Отправлять уведомления** о статусе токенов

## 📱 Как использовать

### 1. Создайте архив с session

**Вариант A - ZIP:**
```bash
zip -r session_backup.zip session/
```

**Вариант Б - 7z:**
```bash
7z a session_backup.7z session/
```

**Структура архива должна быть:**
```
session_backup.zip
└── session/
    ├── accounts/
    │   ├── acc_123/
    │   └── acc_456/
    ├── tokens.json
    └── auth_token.txt
```

### 2. Отправьте в Telegram

1. Откройте вашего бота в Telegram
2. Нажмите 📎 (скрепка)
3. Выберите **Файл** (не фото!)
4. Выберите архив
5. Отправьте

### 3. Бот ответит

```
⏳ Загрузка файла session_backup.zip...
✅ Файл загружен. Распаковка...
✅ Архив успешно распакован!

📂 Папка session обновлена
🔄 Сервис будет перезапущен...

🔄 Перезапуск сервиса...
⏱️ Сервис будет перезапущен в течение 5 секунд
```

### 4. Сервис перезапустится

- Через 3-5 секунд сервис автоматически перезапустится
- Новые сессии будут загружены
- Можно продолжать работу

## ⚙️ Настройка

### В .env файл добавьте:

```bash
# Токен бота от @BotFather
TELEGRAM_BOT_TOKEN=123456789:ABCdefGHIjklMNOpqrsTUVwxyz

# Ваш ID от @userinfobot
TELEGRAM_USER_IDS=123456789

# Время предупреждения токенов (по умолчанию 1 час)
TOKEN_EXPIRY_WARNING_MS=3600000
```

### Пересоберите контейнер:

```bash
docker-compose build
docker-compose up -d
```

## 📏 Лимиты

- **Максимальный размер:** 50MB
- **Поддерживаемые форматы:** .zip, .7z
- **Обязательно:** папка `session/` в архиве


## ❗ Решение проблем

### "Архив не содержит папку session"

**Проблема:** Неправильная структура архива

**Решение:**
```bash
# Правильно:
zip -r session_backup.zip session/

# Неправильно:
cd session && zip -r ../backup.zip *
```

### Файл не принимается

**Проверьте:**
1. Формат: только `.zip` или `.7z`
2. Размер: максимум 50MB
3. Отправляйте как **файл**, не как фото

### Сервис не перезапускается

**Ручной перезапуск:**
```bash
docker-compose restart
```

**Проверка:**
```bash
# Проверить логи
docker-compose logs --tail=50

# Проверить статус
docker-compose ps
```

### Бот не отвечает

**Проверьте:**
1. `TELEGRAM_BOT_TOKEN` правильный
2. Бот не заблокирован
3. Есть интернет до Telegram API

```bash
# Проверка подключения
docker-compose exec qwen-proxy curl https://api.telegram.org
```
