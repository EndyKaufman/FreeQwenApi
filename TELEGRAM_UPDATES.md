# Telegram Bot - Обновления и новые функции

## 🐳 Docker образ

Официальный Docker образ доступен на Docker Hub:

**https://hub.docker.com/r/endykaufman/qwen-api-proxy**

### Быстрый запуск:

```bash
# Pull образа
docker pull endykaufman/qwen-api-proxy:latest

# Запуск
docker run -d \
  --name qwen-api-proxy \
  -p 3264:3264 \
  -v $(pwd)/session:/app/session \
  -v $(pwd)/logs:/app/logs \
  -v $(pwd)/uploads:/app/uploads \
  --env-file .env \
  endykaufman/qwen-api-proxy:latest
```

### Docker Compose:

```yaml
services:
  qwen-proxy:
    image: endykaufman/qwen-api-proxy:latest
    container_name: qwen-proxy
    environment:
      - SKIP_ACCOUNT_MENU=true
      - PORT=3264
    ports:
      - "3264:3264"
    volumes:
      - ./session:/app/session
      - ./logs:/app/logs
      - ./uploads:/app/uploads
    restart: unless-stopped
```

**Преимущества Docker образа:**
- ✅ Мультиплатформенность (linux/amd64, linux/arm64)
- ✅ Автоматические обновления через GitHub Actions
- ✅ Встроенная документация и метаданные
- ✅ Оптимизированный размер
- ✅ Все зависимости включены

### 3. Разделение команд управления LLM чатом

**Раньше:**
- `/chat` - включал/выключал LLM чат

**Теперь:**
- `/chat` - **показывает текущее состояние** LLM чата
- `/togglechat` - **включает/выключает** LLM чат

#### Команда `/chat` показывает:
```
📊 Состояние LLM чата

🔧 Статус: ✅ Включен
🤖 Модель: qwen3.5-plus
💬 Сообщений в контексте: 5

💡 Используйте /togglechat чтобы выключить LLM чат
```

#### Команда `/togglechat`:
- Если LLM выключен → включает
- Если LLM включен → выключает

### 2. Глобальная модель вместо индивидуальных

**Раньше:**
- Каждый чат мог иметь свою модель
- Хранилось в `session/chat_models.json`

**Теперь:**
- Одна глобальная модель для всех чатов
- Хранится в `session/bot_settings.json` в поле `activeModel`
- Проще управление и настройка

#### Команда `/setmodel`:
```
/setmodel qwen3-max

✅ Модель изменена!

🤖 Новая модель: qwen3-max
💬 Будет использоваться во всех чатах
💾 Настройка сохранена
```

## 🔧 Структура настроек

### Файл `session/bot_settings.json`:

```json
{
  "activeModel": "qwen3.5-plus",
  "llmChatEnabled": false,
  "lastUpdated": "2026-05-31T12:32:16.526Z"
}
```

**Поля:**
- `activeModel` - глобальная модель для всех чатов (null = использовать default)
- `llmChatEnabled` - состояние LLM чата (true/false)
- `lastUpdated` - дата последнего обновления

## 📝 Технические детали

### Хранение настроек

**Один файл для всех настроек:**
- `session/bot_settings.json` - все настройки бота
- `session/chat_models.json` - **УДАЛЕН** (больше не используется)

### Приоритет выбора модели

1. `activeModel` из `bot_settings.json` (если установлен)
2. `DEFAULT_MODEL` из `.env` (если установлен)
3. Первая модель из списка доступных
4. Fallback: `qwen3.5-plus` (first model from AvailableModels.txt)

### Проверка AI при запуске

**Процесс:**
1. Загружаются настройки и токены
2. Отправляется тестовый запрос "ping" к Qwen API
3. Измеряется время ответа
4. Результат показывается в статусе

**Если ошибка:**
```
🧠 AI Нейросеть: ❌ Ошибка: All tokens are rate limited (24h)
```
