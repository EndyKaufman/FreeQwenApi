# Быстрая настройка уведомлений в Telegram

## 📱 Шаг 1: Создайте бота в Telegram

1. Откройте Telegram
2. Найдите бота **@BotFather**
3. Отправьте команду `/newbot`
4. Следуйте инструкциям:
   - Введите имя бота (например: `FreeQwenApi Notifier`)
   - Введите username бота (должен заканчиваться на `bot`, например: `freeqwen_monitor_bot`)
5. **Скопируйте токен бота** (выглядит как: `123456789:ABCdefGHIjklMNOpqrsTUVwxyz`)

## 👤 Шаг 2: Узнайте свой Telegram ID

1. Откройте Telegram
2. Найдите бота **@userinfobot**
3. Отправьте любое сообщение
4. Бот ответит с вашим **User ID** (например: `123456789`)
5. **Скопируйте этот ID**

## ⚙️ Шаг 3: Настройте проект

1. Создайте файл `.env` в корне проекта (если его нет):

```bash
# Скопируйте из .env.example
cp .env.example .env
```

2. Откройте `.env` и добавьте:

```bash
# Вставьте токен вашего бота
TELEGRAM_BOT_TOKEN=123456789:ABCdefGHIjklMNOpqrsTUVwxyz

# Вставьте ваш User ID (можно несколько через запятую)
TELEGRAM_USER_IDS=123456789

# Время предупреждения (по умолчанию 1 час)
TOKEN_EXPIRY_WARNING_MS=3600000
```

## ✅ Шаг 4: Проверьте работу

Запустите тест:

```bash
node test_token_expiry.js
```

Вы должны увидеть:
- Статус всех токенов
- Тест отправки Telegram уведомления
- Если всё настроено верно - получите тестовое сообщение в Telegram

## 🎯 Как это работает

### Автоматическая проверка:
- ✅ **Перед каждым запросом** к LLM проверяется время жизни токена
- ⏰ Если токен истекает в течение 1 часа - **пропускается**
- 🔄 Система автоматически выбирает следующую здоровую сессию

### Уведомления:
- 📱 Если **ВСЕ токены истекли** - отправляется уведомление в Telegram
- 📊 В сообщении detailed статус каждого токена
- ⚠️ Вы получаете предупреждение ДО того, как всё сломается

### Пример уведомления:

```
🚨 FreeQwenApi - Проблема с токенами

❌ Все токены недоступны:

1. acc_1234567890
   Статус: ⏰ Истекает через 2 ч.
   Сброс: 09.05.2026, 15:30:00

2. acc_9876543210
   Статус: ❌ Недействителен

⚠️ Требуется действие:
   • Перезапустите авторизацию для обновления токенов
   • Или дождитесь автоматического сброса лимитов
```

## 🔧 Дополнительные настройки

### Изменить время предупреждения:

```bash
# Предупреждать за 30 минут
TOKEN_EXPIRY_WARNING_MS=1800000

# Предупреждать за 2 часа
TOKEN_EXPIRY_WARNING_MS=7200000

# Предупреждать за 30 минут до истечения
TOKEN_EXPIRY_WARNING_MS=1800000
```

### Несколько пользователей:

```bash
# Добавьте ID через запятую
TELEGRAM_USER_IDS=123456789,987654321,456789123
```

### Отключить уведомления:

Просто удалите или закомментируйте строки в `.env`:

```bash
# TELEGRAM_BOT_TOKEN=...
# TELEGRAM_USER_IDS=...
```

Система продолжит проверять токены, но не будет отправлять уведомления.

## 📊 Мониторинг

Смотрите логи для отслеживания статуса токенов:

```bash
# Последние события с токенами
tail -f logs/combined.log | grep "токен"

# Уведомления Telegram
tail -f logs/combined.log | grep "Telegram"

# Предупреждения об истечении
tail -f logs/combined.log | grep "истекает"
```

## ❓ Частые вопросы

### Q: Что если я не настрою Telegram?
A: Система будет работать как раньше - проверять токены и пропускать истекающие, просто без уведомлений.

### Q: Можно добавить несколько ботов?
A: Нет, используется один бот для отправки уведомлений нескольким пользователям.

### Q: Как часто проверяются токены?
A: Перед КАЖДЫМ запросом к LLM.

### Q: Что происходит когда все токены истекли?
A: 
1. Отправляется уведомление в Telegram
2. Система пробует использовать любой доступный токен (даже истекающий)
3. Если токенов совсем нет - возвращается ошибка

### Q: Как сбросить лимиты токенов?
A: Отредактируйте `session/tokens.json` и удалите поля `resetAt` у нужных токенов.

## 🐛 Решение проблем

### Не приходят уведомления:
1. Проверьте правильность `TELEGRAM_BOT_TOKEN`
2. Убедитесь что `TELEGRAM_USER_IDS` содержит правильные ID
3. Проверьте что вы не заблокировали бота
4. Посмотрите логи на ошибки

### Токены не переключаются:
1. Проверьте `session/tokens.json` - есть ли там токены
2. Посмотрите логи - какие токены выбираются
3. Убедитесь что `resetAt` указаны правильно

### Тест не работает:
```bash
# Проверьте что файл существует
ls -la test_token_expiry.js

# Запустите с выводом отладки
NODE_ENV=development node test_token_expiry.js
```
