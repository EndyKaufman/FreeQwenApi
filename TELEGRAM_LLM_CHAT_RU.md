# Telegram Bot - LLM Чат (AI Ассистент)

## 🎯 Что добавлено

Теперь Telegram бот может **отвечать на сообщения** используя Qwen AI!

## 🚀 Быстрый старт

### 1. Включите LLM чат

Отправьте команду:
```
/chat
```

Бот ответит:
```
✅ LLM чат включен!
🤖 Теперь я отвечаю как AI ассистент.
```

### 2. Отправьте сообщение

Просто напишите что-нибудь:

**Вы:**
```
Привет! Как дела?
```

**Бот:**
```
Привет! У меня всё отлично, спасибо! 😊
Я готов помочь вам с вопросами.
```

### 3. Выключите когда не нужно

```
/chat
```

Бот ответит:
```
❌ LLM чат выключен
Возвращен в режим управления ботом.
```

## 📋 Команды для LLM чата

| Команда | Описание |
|---------|----------|
| `/chat` | Включить/выключить LLM чат |
| `/clear` | Очистить историю переписки |
| `/model` | Показать текущую модель |

## 🔧 Как это работает

```
Пользователь отправляет сообщение
         ↓
Бот проверяет: LLM режим включен?
         ↓
ДА → Отправляет в Qwen API
         ↓
    http://localhost:3264/api/chat/completions
         ↓
Отправляет запрос с контекстом:
{
  "messages": [
    {"role": "user", "content": "сообщение 1"},
    {"role": "assistant", "content": "ответ 1"},
    {"role": "user", "content": "текущее сообщение"}
  ],
  "model": "qwen-max-latest"
}
         ↓
Получает ответ
         ↓
Сохраняет в контекст
         ↓
Отправляет пользователю в Telegram
```

## 📊 Контекст чата

- **Максимум сообщений:** 20 (последние 10 пар)
- **Автоочистка:** Старые сообщения удаляются
- **Ручная очистка:** Команда `/clear`
- **Для каждого пользователя:** Отдельный контекст

## ⚙️ Настройка модели

### Текущая модель

Используется модель из `.env`:
```bash
DEFAULT_MODEL=qwen-max-latest
```

### Доступные модели

- `qwen-max-latest` - Самая мощная (по умолчанию)
- `qwen-plus` - Баланс скорости и качества
- `qwen-turbo` - Быстрые ответы
- `qwen3-max` - Последняя Qwen 3
- `qwen-vl-max` - С поддержкой изображений

### Сменить модель

1. Отредактируйте `.env`:
   ```bash
   DEFAULT_MODEL=qwen-turbo
   ```

2. Перезапустите:
   ```bash
   docker-compose restart
   ```

## ⚠️ Важно

### Лимиты

- Бот использует те же токены Qwen что и сервис
- Подвержен лимитам Qwen API
- Если все токены истекли - LLM чат не работает

### Время ответа

- Зависит от модели и сложности
- Обычно 2-10 секунд
- Показывает "печатает..." пока ждет

### Приватность

- Сообщения хранятся только в памяти
- Очищаются при перезапуске
- Не сохраняются в логах
- Используйте `/clear` для очистки

## 🐛 Решение проблем

### LLM чат не работает

**Проверьте:**
```bash
# Сервис запущен?
docker-compose ps

# API доступен?
curl http://localhost:3264/api/status

# Логи
docker-compose logs | grep "LLM Chat"
```

**Решения:**
1. Убедитесь что сервис работает
2. Проверьте что токены доступны
3. Проверьте API endpoint

### Ошибка "Qwen API error"

**Причина:** Токены истекли или лимит превышен

**Решение:**
```bash
# Проверить статус токенов
curl http://localhost:3264/api/status

# Загрузить новые сессии через бота
```

### Долгие ответы

**Причины:**
- Сложный запрос
- Модель загружена
- Проблемы с сетью

**Решения:**
1. Задавайте проще вопросы
2. Используйте `qwen-turbo` для скорости
3. Проверьте интернет
